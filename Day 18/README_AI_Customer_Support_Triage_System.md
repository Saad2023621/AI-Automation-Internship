## 1. Project Name
**AI Customer Support Triage System**

## 2. Problem Statement
Customer support messages often require manual classification before they can be assigned to the correct department. This workflow automates the initial triage process using AI.

It receives a customer support message through an n8n Webhook, analyzes it with Google Gemini, forces the result into structured JSON, routes the ticket by category, stores the ticket in Google Sheets, sends an acknowledgment email, and sends an urgent alert for high-priority tickets.

## 3. Objective
The workflow must:
- Receive customer support messages through a Webhook.
- Analyze messages using an LLM.
- Return predictable structured JSON.
- Determine category, priority, sentiment, department, summary, and suggested response.
- Route tickets by category.
- Preserve customer name, email, and ticket ID.
- Store processed tickets in Google Sheets.
- Send an automatic acknowledgment email.
- Alert the team when priority is High.

## 4. Workflow Architecture

**Customer → Webhook → Basic LLM Chain → Structured Output Parser → Edit Fields → Switch by Category → Google Sheets → Gmail**

Urgent branch:

**Processed Ticket → Check Urgent Priority → Gmail Urgent Alert**

### Main Nodes
1. **Webhook** - receives the POST request.
2. **Basic LLM Chain** - sends the customer message to the AI model.
3. **Google Gemini Chat Model** - provides the AI model.
4. **Structured Output Parser** - validates the required JSON structure.
5. **Edit Fields** - restores original `name`, `email`, and `ticket_id`.
6. **Switch - Route by Ticket Category** - routes Sales, Support, Complaint, Invoice, Spam, or General.
7. **Append Row in Sheet** - stores the ticket.
8. **Send a Message** - sends the customer acknowledgment.
9. **Check Urgent Priority** - checks whether priority equals High.
10. **Send a Message 1** - sends an urgent internal notification.

## 7. AI Prompt

The Basic LLM Chain uses a prompt based on the following instructions:

```text
You are an AI customer support triage system.

Analyze the customer support message and return only valid structured JSON.

Determine:
- category
- priority
- sentiment
- department
- summary
- suggested_response

Allowed categories:
Sales, Support, Complaint, Invoice, Spam, General

Allowed priorities:
Low, Medium, High

Allowed sentiments:
Positive, Neutral, Negative

Rules:
- Select exactly one category.
- Select exactly one priority.
- Select exactly one sentiment.
- Assign the most appropriate department.
- Keep the summary concise and factual.
- Write a professional and helpful suggested response.
- Do not invent facts.
- Do not return Markdown or explanations outside the JSON response.

Customer name:
{{ customer name }}

Customer email:
{{ customer email }}

Customer message:
{{ customer message }}
```

The actual n8n expressions should reference the fields coming from the Webhook.

## 8. Structured JSON Schema

```json
{
  "type": "object",
  "properties": {
    "category": {
      "type": "string",
      "enum": ["Sales", "Support", "Complaint", "Invoice", "Spam", "General"]
    },
    "priority": {
      "type": "string",
      "enum": ["Low", "Medium", "High"]
    },
    "sentiment": {
      "type": "string",
      "enum": ["Positive", "Neutral", "Negative"]
    },
    "department": {
      "type": "string"
    },
    "summary": {
      "type": "string"
    },
    "suggested_response": {
      "type": "string"
    }
  },
  "required": [
    "category",
    "priority",
    "sentiment",
    "department",
    "summary",
    "suggested_response"
  ]
}
```

## 9. Important Data Handling

The AI structured output contains the fields generated by the model, but the original customer metadata may not remain available after the parser.

Therefore, an **Edit Fields** node is used after the Structured Output Parser to restore:
- `name`
- `email`
- `ticket_id`

If the Webhook data is inside `body`, the expressions are:

```text
{{ $('Webhook').item.json.body.name }}
```

```text
{{ $('Webhook').item.json.body.email }}
```

```text
{{ $('Webhook').item.json.body.ticket_id }}
```

After this step, the item should contain both the original customer information and the AI-generated fields.

## 11. Switch Routing

The Switch node routes using:

```text
{{ $json.category }}
```

Routes:
- Sales
- Support
- Complaint
- Invoice
- Spam
- General

The exact expression should match the JSON structure visible after the Edit Fields node.

## 12. Urgent Priority

The urgent IF node checks:

```text
priority is equal to High
```

If **true**, Gmail sends an internal alert such as:

```text
URGENT CUSTOMER SUPPORT TICKET

Ticket ID: {{ $json.ticket_id }}
Customer: {{ $json.name }}
Email: {{ $json.email }}
Category: {{ $json.category }}
Priority: {{ $json.priority }}
Department: {{ $json.department }}

Summary:
{{ $json.summary }}
```

If false, no urgent alert is sent.

## 13. Customer Acknowledgment

The Gmail **To** field should use:

```text

```

Example subject:



## 16. Error Handling

### Invalid AI response
The Structured Output Parser validates the response against the required structure.

### Missing customer information
Verify `name`, `email`, and `ticket_id` before saving or emailing the ticket.

### Invalid category
The Switch should have a no-match/fallback route where appropriate.

### AI provider unavailable
The workflow may fail if the configured AI provider is unavailable. n8n retry/error handling can be configured for production use.

### Invalid email
Do not send an acknowledgment if the customer email is missing or invalid.

## 21. Known Limitations

- AI classifications can occasionally be incorrect.
- Priority depends on the wording and context of the message.
- The workflow depends on the availability of the AI provider.
- Email delivery depends on Gmail configuration.
- The workflow does not directly resolve customer account issues.
- Google Sheets is suitable for this internship demonstration but is not an ideal high-volume production ticket database.

## 24. Conclusion

The AI Customer Support Triage System demonstrates a complete AI-powered automation pipeline in n8n. It converts an unstructured customer message into structured ticket information, routes the ticket by category, stores the ticket, acknowledges the customer, and escalates high-priority issues to a human team.

This workflow demonstrates practical use of Webhooks, LLMs, structured output validation, conditional routing, Google Sheets, and Gmail in an automated customer-support process.
